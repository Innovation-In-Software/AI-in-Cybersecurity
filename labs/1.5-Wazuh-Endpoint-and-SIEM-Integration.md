## Lab 3.0 (Optional): Wazuh Endpoint Telemetry and SIEM Integration

This optional lab adds an endpoint security data source to your workflow. You will install a Wazuh agent on Amazon Linux 2023, generate controlled suspicious activity, export Wazuh alerts, and forward them into a SIEM-ready format.

This lab is intentionally bounded: Wazuh is used as an event source for SOC automation, not as the main course topic.

## Learning Objectives

By the end of this lab, you will be able to:

1. Install and enroll a Wazuh agent on an EC2 endpoint.
2. Generate endpoint events that Wazuh can detect.
3. Export Wazuh alerts in JSON format.
4. Forward alerts to a SIEM ingestion endpoint (Splunk HEC example).
5. Produce a ranked alert summary with Python.

## Part 1: Install Wazuh Agent on Amazon Linux 2023

1. Add the Wazuh repository and install the agent.

```bash
sudo rpm --import https://packages.wazuh.com/key/GPG-KEY-WAZUH
sudo curl -s -o /etc/yum.repos.d/wazuh.repo https://packages.wazuh.com/4.x/yum/wazuh.repo
sudo dnf install -y wazuh-agent
```

2. Configure manager address and agent identity.

```bash
sudo sed -i 's|<address>MANAGER_IP</address>|<address>WAZUH_MANAGER_IP</address>|' /var/ossec/etc/ossec.conf
sudo sed -i 's|<agent_name>.*</agent_name>|<agent_name>WAZUH_AGENT_NAME</agent_name>|' /var/ossec/etc/ossec.conf
```

3. Start and enable the agent.

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now wazuh-agent
sudo systemctl status wazuh-agent --no-pager
```

Note:
- If your Wazuh environment uses enrollment keys or a different bootstrap method, follow your instructor-provided enrollment command and then continue.

## Part 4: SIEM Forwarding (Splunk HEC Example)

Create a forwarder script named `forward_to_splunk.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

INPUT_FILE="${1:-~/wazuh-alerts-medium-plus.jsonl}"
HEC_URL="${SPLUNK_HEC_URL:-https://SPLUNK_HOST:8088/services/collector/event}"
HEC_TOKEN="${SPLUNK_HEC_TOKEN:-REPLACE_ME}"

if [[ ! -f "$INPUT_FILE" ]]; then
  echo "Input file not found: $INPUT_FILE"
  exit 1
fi

while IFS= read -r line; do
  [[ -z "$line" ]] && continue
  payload=$(jq -cn --argjson ev "$line" '{event:$ev, sourcetype:"wazuh:alert", index:"main"}')
  curl -sS -k "$HEC_URL" \
    -H "Authorization: Splunk $HEC_TOKEN" \
    -H "Content-Type: application/json" \
    -d "$payload" > /dev/null
done < "$INPUT_FILE"

echo "Forward complete"
```

Run it:

```bash
chmod +x forward_to_splunk.sh
export SPLUNK_HEC_URL="https://YOUR_SPLUNK_HOST:8088/services/collector/event"
export SPLUNK_HEC_TOKEN="YOUR_HEC_TOKEN"
./forward_to_splunk.sh ~/wazuh-alerts-medium-plus.jsonl
```

Verify in Splunk by searching for sourcetype `wazuh:alert`.

## Part 5: Python Alert Ranking for Analyst Triage

Create `wazuh_alert_ranker.py`:

```python
import json
from collections import Counter, defaultdict

INPUT_FILE = "wazuh-alerts-medium-plus.jsonl"


def severity_bucket(level):
    if level >= 12:
        return "high"
    if level >= 7:
        return "medium"
    return "low"


def score_event(level, groups):
    score = level
    g = set(groups or [])
    if "authentication_failed" in g:
        score += 3
    if "sshd" in g:
        score += 2
    if "syscheck" in g:
        score += 2
    if "rootcheck" in g:
        score += 4
    if "sudo" in g:
        score += 2
    return score


def main():
    totals = defaultdict(lambda: {"score": 0, "count": 0, "top_rules": Counter(), "evidence": []})

    with open(INPUT_FILE, "r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                ev = json.loads(line)
            except json.JSONDecodeError:
                continue

            rule = ev.get("rule", {})
            level = int(rule.get("level", 0))
            groups = rule.get("groups", [])
            agent = ev.get("agent", {}).get("name", "unknown-agent")
            desc = rule.get("description", "no-description")
            score = score_event(level, groups)

            totals[agent]["score"] += score
            totals[agent]["count"] += 1
            totals[agent]["top_rules"][desc] += 1
            if len(totals[agent]["evidence"]) < 3:
                totals[agent]["evidence"].append({
                    "level": level,
                    "severity": severity_bucket(level),
                    "description": desc,
                })

    ranked = sorted(totals.items(), key=lambda x: x[1]["score"], reverse=True)

    print("agent,total_score,event_count,top_rule")
    for agent, data in ranked:
        top_rule = data["top_rules"].most_common(1)[0][0] if data["top_rules"] else "none"
        print(f"{agent},{data['score']},{data['count']},{top_rule}")

    print("\nEvidence:")
    for agent, data in ranked[:5]:
        print(f"\n[{agent}] score={data['score']} events={data['count']}")
        for ev in data["evidence"]:
            print(f"- level={ev['level']} severity={ev['severity']} desc={ev['description']}")


if __name__ == "__main__":
    main()
```

Run it:

```bash
python3 wazuh_alert_ranker.py
```
