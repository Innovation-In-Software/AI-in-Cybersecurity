## Lab 5.0: Event-Driven Bedrock SOC Triage Automation

In this lab, you will operationalize the Bedrock triage workflow from Lab 4.0. Instead of invoking Lambda manually, you will upload Wazuh alert files into Amazon S3, trigger the Lambda function automatically, and store the triage result as a structured JSON artifact for later analyst review or SIEM ingestion.

This lab is about automation, not new AI behavior. The Bedrock Agent prompt and output contract stay the same. The new skill is wiring event-driven cloud workflow around the agent.

## Learning Objectives

By the end of this lab, you will be able to:

1. Build an S3-based event trigger for AI triage.
2. Extend the Lambda workflow to read from S3 and write normalized output.
3. Store triage artifacts for later review and downstream integration.
4. Validate an event-driven SOC automation path on AWS.

---

## Architecture

1. Wazuh alert file from Lab 3 is uploaded to S3.
2. S3 triggers the Lambda function from Lab 4.
3. Lambda reads and sanitizes the alert data.
4. Lambda invokes the Bedrock Agent.
5. Lambda validates the JSON response.
6. Lambda writes the triage result back to S3.
7. Analyst reviews the stored result before any action is taken.

## Part 1: Create S3 Buckets for Input and Output

1. Set shell variables.

```bash
export AWS_REGION=us-east-1
export INPUT_BUCKET=YOUR_UNIQUE_INPUT_BUCKET_NAME
export OUTPUT_BUCKET=YOUR_UNIQUE_OUTPUT_BUCKET_NAME
```

2. Create the buckets.

```bash
aws s3 mb s3://$INPUT_BUCKET --region $AWS_REGION
aws s3 mb s3://$OUTPUT_BUCKET --region $AWS_REGION
```

3. Create logical prefixes.

```bash
aws s3api put-object --bucket $INPUT_BUCKET --key incoming/
aws s3api put-object --bucket $OUTPUT_BUCKET --key triage-results/
```

## Part 2: Update the Lambda Function for S3 Input and Output

Add these environment variables to the Lambda function:

- `OUTPUT_BUCKET`
- `OUTPUT_PREFIX=triage-results/`

Update the Lambda IAM role to include S3 access:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:GetObject"
      ],
      "Resource": "arn:aws:s3:::YOUR_UNIQUE_INPUT_BUCKET_NAME/*"
    },
    {
      "Effect": "Allow",
      "Action": [
        "s3:PutObject"
      ],
      "Resource": "arn:aws:s3:::YOUR_UNIQUE_OUTPUT_BUCKET_NAME/*"
    }
  ]
}
```

Replace the Lambda handler with this version:

```python
import json
import os
import uuid
from urllib.parse import unquote_plus

import boto3

s3 = boto3.client("s3")
agent_runtime = boto3.client("bedrock-agent-runtime")

OUTPUT_BUCKET = os.environ["OUTPUT_BUCKET"]
OUTPUT_PREFIX = os.environ.get("OUTPUT_PREFIX", "triage-results/")
AGENT_ID = os.environ["AGENT_ID"]
AGENT_ALIAS_ID = os.environ["AGENT_ALIAS_ID"]

REQUIRED_FIELDS = {
    "severity",
    "confidence",
    "summary",
    "iocs",
    "likely_techniques",
    "evidence",
    "recommended_next_steps",
    "escalation_recommended",
    "uncertainty_notes",
}


def sanitize_alerts(raw_text, max_events=10):
    sanitized = []
    for line in raw_text.splitlines():
        line = line.strip()
        if not line:
            continue
        try:
            ev = json.loads(line)
        except json.JSONDecodeError:
            continue

        rule = ev.get("rule", {})
        agent = ev.get("agent", {})
        data = {
            "timestamp": ev.get("timestamp"),
            "agent_name": agent.get("name"),
            "rule_level": rule.get("level"),
            "rule_description": rule.get("description"),
            "rule_groups": rule.get("groups", []),
            "full_log": ev.get("full_log", "")[:300],
        }
        sanitized.append(data)
        if len(sanitized) >= max_events:
            break
    return sanitized


def invoke_agent(alerts):
    prompt = {
        "task": "triage_security_alerts",
        "alerts": alerts,
        "instructions": "Return JSON only. Ground findings in the alerts."
    }

    response = agent_runtime.invoke_agent(
        agentId=AGENT_ID,
        agentAliasId=AGENT_ALIAS_ID,
        sessionId=str(uuid.uuid4()),
        inputText=json.dumps(prompt),
    )

    parts = []
    for event in response["completion"]:
        chunk = event.get("chunk")
        if chunk and "bytes" in chunk:
            parts.append(chunk["bytes"].decode("utf-8"))

    text = "".join(parts).strip()
    return json.loads(text)


def validate_result(result):
    missing = REQUIRED_FIELDS - set(result.keys())
    if missing:
        raise ValueError(f"Missing required fields: {sorted(missing)}")

    if result["severity"] not in {"low", "medium", "high"}:
        raise ValueError("Invalid severity value")

    if not isinstance(result["confidence"], int):
        raise ValueError("confidence must be an integer")


def lambda_handler(event, context):
    record = event["Records"][0]
    input_bucket = record["s3"]["bucket"]["name"]
    input_key = unquote_plus(record["s3"]["object"]["key"])

    obj = s3.get_object(Bucket=input_bucket, Key=input_key)
    raw_text = obj["Body"].read().decode("utf-8")
    alerts = sanitize_alerts(raw_text)

    result = invoke_agent(alerts)
    validate_result(result)

    output_key = f"{OUTPUT_PREFIX}{os.path.basename(input_key)}.triage.json"
    body = {
        "source_file": input_key,
        "alert_count_used": len(alerts),
        "triage": result,
    }

    s3.put_object(
        Bucket=OUTPUT_BUCKET,
        Key=output_key,
        Body=json.dumps(body, indent=2).encode("utf-8"),
        ContentType="application/json",
    )

    return {
        "statusCode": 200,
        "output_key": output_key,
        "alert_count_used": len(alerts),
    }
```

## Part 3: Configure the S3 Trigger

1. Open the Lambda function.
2. Add an S3 trigger.
3. Select the input bucket.
4. Limit the prefix to `incoming/`.
5. Enable the trigger.

Expected result:

- Any new file placed into `s3://INPUT_BUCKET/incoming/` triggers the Lambda function.

## Part 4: Test the Event-Driven Workflow

1. Copy the Wazuh alert file into the input bucket.

```bash
aws s3 cp wazuh-alerts-medium-plus.jsonl s3://$INPUT_BUCKET/incoming/wazuh-alerts-medium-plus.jsonl
```

2. Check the Lambda logs.

```bash
aws logs tail /aws/lambda/soc-triage-bedrock-handler --follow
```

3. List the output bucket.

```bash
aws s3 ls s3://$OUTPUT_BUCKET/triage-results/
```

4. Download the triage result.

```bash
aws s3 cp s3://$OUTPUT_BUCKET/triage-results/wazuh-alerts-medium-plus.jsonl.triage.json .
cat wazuh-alerts-medium-plus.jsonl.triage.json
```

Expected result:

- You should see a stored JSON triage artifact with severity, confidence, summary, evidence, and recommended next steps.
